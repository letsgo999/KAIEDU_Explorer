KKAIEDU Explorer
기능데이터 사용다운로드개인정보처리방침
Tiny Windows Utility · Open Source

Google Drive와 로컬 파일을
한 화면에서 더 빠르게

탐색기 두 창을 좌우에 배치하고 마지막 경로를 기억합니다. 동기화된 파일이나 폴더는 우클릭 한 번으로 Google Drive 웹 주소를 복사할 수 있습니다.

사용 조건: Windows 10/11과 Google Drive 데스크톱 앱이 필요합니다. Drive 문자는 G:로 고정하지 않고 자동 탐지하므로 기존 로컬 G: 드라이브를 변경하거나 덮어쓰지 않습니다.

최신 버전 다운로드 작동 방식 보기
초경량외부 프레임워크와 별도 서버가 없습니다.
최소 권한Drive 메타데이터 읽기 권한만 요청합니다.
로컬 우선경로와 토큰은 사용자 PC에만 저장합니다.
Features

파일 이동과 링크 공유에 필요한 것만

복잡한 파일 관리자를 새로 배우지 않고 Windows 탐색기 사용 흐름을 그대로 유지합니다.

01

두 창 자동 배치

두 탐색기를 빈틈없이 붙여 열고 중앙선을 드래그해 너비를 조절합니다. 더블클릭하면 50:50으로 복원됩니다.

02

마지막 경로 기억

앱을 닫기 전 탐색하던 양쪽 위치를 저장해 다음 실행 때 복원합니다.

03

Drive URL 복사

Windows 11 추가 옵션 메뉴에서 동기화된 파일과 폴더의 웹 주소를 복사합니다.

How it works

API는 URL을 요청할 때만

STEP 1

앱 실행

탐색기 두 창을 열고 저장된 경로와 화면 분할을 복원합니다. 이 단계에서는 Google API를 호출하지 않습니다.

STEP 2

파일 또는 폴더 선택

Google Drive 데스크톱 앱이 연결한 드라이브에서 항목을 우클릭합니다.

STEP 3

URL 복사

메뉴를 선택한 순간에만 Drive API로 해당 항목의 비공개 webViewLink를 조회합니다.

Google user data

파일 내용은 읽지 않습니다

KAIEDU Explorer는 링크 확인에 필요한 Drive 메타데이터만 사용합니다.

요청 범위

https://www.googleapis.com/auth/drive.metadata.readonly

파일·폴더 이름, 식별자, 상위 폴더 관계와 웹 보기 링크를 읽는 권한입니다.

  • 파일 본문을 읽거나 업로드하지 않습니다.
  • 공유 권한을 생성·수정하지 않습니다.
  • Google 사용자 데이터를 광고나 AI 학습에 사용하지 않습니다.
  • 토큰은 Windows DPAPI로 암호화해 로컬에만 저장합니다.
  • 별도 서버, 분석 도구, 텔레메트리가 없습니다.
