개인정보처리방침

시행일: 2026년 9월 25일

KAIEDU Explorer의 Google API 사용은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.

1. 앱과 운영자

KAIEDU Explorer는 한국인공지능교육센터(KAIEDU)가 제공하는 Windows용 오픈소스 파일 탐색 보조 도구입니다. 문의는 KAIEDU 공식 홈페이지의 문의 채널을 이용할 수 있습니다.

2. 접근하는 Google 사용자 데이터

앱은 사용자가 선택한 Google Drive 항목의 웹 주소를 찾기 위해 drive.metadata.readonly 범위를 요청합니다. 파일·폴더 이름, 식별자, 상위 폴더 관계, MIME 유형 및 webViewLink 같은 메타데이터를 읽을 수 있습니다.

3. 사용 목적

Google 사용자 데이터는 로컬 경로에 대응하는 Google Drive 웹 보기 주소를 찾아 사용자의 클립보드에 복사하는 기능에만 사용합니다.

4. 저장과 보호

  • OAuth 액세스·갱신 토큰과 클라이언트 정보는 사용자 PC의 %LOCALAPPDATA%\DualDriveExplorer\settings.json에 Windows DPAPI CurrentUser 방식으로 암호화하여 저장합니다.
  • 운영자 서버로 Google 사용자 데이터나 토큰을 전송하거나 저장하지 않습니다.
  • 분석, 광고, 프로파일링 또는 AI 모델 학습에 Google 사용자 데이터를 사용하지 않습니다.

5. 공유와 제3자 제공

앱은 Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. Google Drive API와 OAuth 인증을 위한 Google 서비스 외에는 데이터를 전송하지 않습니다.

6. 파일 내용과 권한

앱은 파일 본문을 읽거나 다운로드하지 않으며 공유 설정을 생성·변경하지 않습니다. 복사되는 링크는 기존 권한을 그대로 유지합니다.

7. 보유 기간과 삭제

로컬 설정과 암호화 토큰은 사용자가 삭제할 때까지 보관됩니다. 연결 해제는 Google 계정의 보안 설정에서 앱 접근 권한을 철회하고, 로컬 settings.json을 삭제하여 완료할 수 있습니다. 앱 제거 스크립트는 실수로 인증정보를 잃지 않도록 설정 파일을 기본 보존하므로 완전 삭제를 원할 때는 사용자가 설정 파일도 직접 삭제해야 합니다.

8. 오픈소스

앱의 동작은 공개 소스 저장소에서 검토할 수 있습니다. OAuth 클라이언트 JSON과 사용자 토큰은 공개 저장소에 포함되지 않습니다.

9. 변경

데이터 사용 방식이나 요청 범위가 변경되면 이 페이지와 앱 내 고지를 갱신하고 필요한 경우 Google의 재검증을 받습니다.
